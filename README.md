# Turn-Based Game Prototype

A lightweight turn-based game prototype for testing combat, events and character progression.

This repository is prepared for experimenting with basic RPG-like gameplay systems, including turn order, attributes, event triggers and simple progression loops.

## Features

- Turn-based combat testing
- Character attribute prototype
- Event and decision flow
- Simple progression loop
- Mobile game experiment foundation

## Project Status

Early testing stage. This repository is mainly used for gameplay logic experiments.

## Roadmap

- Add player and enemy data structure
- Add event trigger system
- Add save/load prototype
- Improve mobile UI layout
